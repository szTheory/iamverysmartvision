**Tracer scope, stated so it is not read as a gap.** The tracer covers every **library** layer the phase modifies: the format, the executor's schedule, the applied-event prefix, the report and the in-process harness. It does not cover `runner/main.c`'s file I/O, because no in-process test can reach `hostio.c` (the fault framework cannot compile it, and the in-process host is a fake) — the operator layer's proof is a process case in plan 11-04, the same split plan 08-16 used for the round-trip hook.

A plan that shipped the library alone would be a horizontal layer with nothing a user could do at the end of it.
