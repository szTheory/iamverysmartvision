| Boundary | Description |
|----------|-------------|
| the operator's file system → the runner | two new paths cross here: one is created exclusively, the other is read bounded; a symlink, a FIFO, a directory or an oversize file must each be refused rather than followed, read or truncated |
| a malformed log → the runner's flow | the log is parsed before any output exists, so a refusal leaves no state; if the parse moved after the first create, a refusal would leave a truncated file behind |
| the log's rights posture → the operator-content refusals | the log must **not** be refused for `content ... user` (it holds no content bytes), while every derived-art output must be; a copy-paste that adds the log to those blocks would silently break D15 |
| a produced log file → the rights check | this is the only place a log is a file at all, so it is the only place the check can be proved against a real artifact |
