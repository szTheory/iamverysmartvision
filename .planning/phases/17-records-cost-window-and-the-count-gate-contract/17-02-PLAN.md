    address space allows at base `4000` is 49,152 words — say plainly that a 65,536-word input crosses the

    `4000` or a base that is not four hex digits is refused while `4000` is accepted and `FFFF` is accepted for

    the work tree and not under `refs/` is refused however it is spelled, while an output outside the tree and
    any path under `refs/` is accepted; an output path that already exists is refused and the refused run

    refused because a segment holds at least one word, while one word is the smallest legal container.
