## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted container bytes -> parser | lengths, counts and offsets come from the input |
| fixtures -> expectations | digests computed by the code under test would be circular |
| repository -> rights | a binary container could slip in as a fixture |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-22 | Information disclosure | out-of-bounds read on a lying container | high | mitigate | offsets derived from checked counts only, exact-size heap buffers under ASan in the dev preset, truncation fixtures N01, N02, N10, N30 |
