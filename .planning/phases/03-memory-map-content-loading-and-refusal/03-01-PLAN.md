Output: generalized `c-faults.sh`, `faults-verdict.sh`, `tests/faults.cmake` with a suite registry in `tests/CMakeLists.txt`; a second toy faults file in the good tree; four controls.

## Trust Boundaries

| Boundary | Description |

| fault inventory -> gate verdict | a fault listed in a second file could be silently skipped or mis-credited |
| core sources -> site scan | a site of one file could be reported as an orphan of another, or a missing site hidden |
