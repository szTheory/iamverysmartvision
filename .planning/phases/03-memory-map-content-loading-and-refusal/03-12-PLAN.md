Reset reading (planner, recorded for the effect table of plan 03-13): reset is allowed from OFF and from POWERED (a power cycle) and gives the same state for the same content; checks run BAD_ARG (unknown kind, A-08e: unknown enumerants are BAD_ARG; UNSUPPORTED is only for unknown option flags and struct tails), then BAD_HANDLE, then MISSING_SYSTEM_IMAGE (EXEC slot checked before GROM). A-08d: after the first successful reset the instance never returns to OFF (only `destroy` ends it), so every later load or unload is BAD_STATE; hosts that want new content create a new instance. Stand-in programs are hand-assembled decle literals whose encodings are taken from the project's own Phase 2 vector data (`data/cp1610/vectors/*.json`), never from an assembler or another emulator (D4).
