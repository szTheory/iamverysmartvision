## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build-tree generated code -> core library | generated text bypassed the source-layer purity rules |
| public headers -> consumers | internal headers leaking through the library's public include path |
| core data -> instances | a writable static would be shared mutable state across instances |
