<objective>
Open the seam end to end with the thinnest slice that touches every layer the phase will modify: a
build-only shared object over the unchanged static core, and a fake frontend that `dlopen`s it, drives the
project's own `lamp-tone.ivsc` to tick 806568, and prints the runner's nine digest lines.

Purpose: prove the architecture on one path before nine more assertions, three guards and a packaging
retarget build on it. If the seam is wrong — a hidden-visibility object that exports nothing, a sanitized
`.so` that will not load, a frame-only drive that moves seven lines — this is the commit that says so,
once, cheaply.
Output: `host/` (the header, the shim, the target with its linker-enforced export list), the harness under
`tests/host/`, the export/import check, the two `.ids` contracts, and the phase's first two
`runner-process` ids.

Locked decisions discharged here, by id: **D-48** (no vendored frontend header; the subset is
project-authored and says *libretro-shaped*, never compatible), **D-35** (the package stays static, so
`IVS_API` is defined for the shared target only and every installed header keeps it empty), and **D-01**
(the core takes no allocator, so the shim owns and aligns the instance storage itself).
</objective>

    (c) `host/ivs_retro_shim.c`: the nine entries, no more. `retro_init` allocates the instance storage with
