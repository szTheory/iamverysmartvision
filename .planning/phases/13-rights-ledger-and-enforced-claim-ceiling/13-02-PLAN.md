## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| data-declared token → tracked path | the refused spelling set is data, the scope is a path predicate; a too-wide match refuses the core, a too-narrow one refuses nothing |
| pin file → scan result | the pin list is the only thing that suppresses a finding, so it must not widen and must not rot |
| claim row → profile field tag | the tier of a dependency comes from `data/profiles/*.json`, read once per profile and cached |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-13-07 | Tampering | `data/expected/rights-pinned.ids` rotting into a wildcard | high | mitigate | The two-field grammar (`rights-pinned-malformed`) plus the reverse direction as a failure (`rights-pinned-stale`); the control plants an unmatched pin and expects the finding. |
