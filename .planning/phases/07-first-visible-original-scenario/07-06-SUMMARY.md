## Decisions Made

- Keep the default form B and N = 500 of the derivation: the measured `EIS` position (9,225 to 9,567) is about 5,400 cycles from each edge, so the mutants of plan 07-08 need no band-edge hugging.
- Do not hold any state in a register across interrupts: the routine saves nothing, `DECR R6` discards the return address, and main code is `EIS` and a branch to itself.
- A hard stop of the phase is machine-checked at the layer that sees names (the `files` step), at the narrow scope the plan states, rather than by a content scan.
