## Accepted risks log

- **T-08-SC (high, accept):** no package manager and no dependency in Phase 8; the core, the tools and the bench tool have zero runtime dependencies, and no benchmark library was added. Repeats T-07-SC and T-06-SC.
- **T-08-38 / R-08-A (medium, accept):** a snapshot of an owner-image (`content ... user`) run lives in the runner's memory for the length of one cut and is never written; the hook is allowed for user content for that reason. Any future snapshot file option is deferred and `ivsn` is already treated as rights-bearing (`binary-ext.txt`, `.gitignore`, `docs/owner-images.md`). Residual: process memory of the runner during an owner-run; the owner-run helper (`tools/owner-run.sh`, Phase 7) remains the only route and is refused in CI.
- **R-08-B (low, T-08-08 residual):** `.planning/config.json` still carries `git.create_tag: true` (the change is an orchestrator-only separate commit recorded in `.planning/ops/RELEASE-OPS.md` section (a) and not made at the Phase 8 close because the owner paused after Phase 8). The strict workflow glob and the `tools/release.sh` tag-form check refuse a v1.0-style tag in the meantime.
- **R-08-C (low, hygiene history):** six history findings (five `hygiene-history-home-path`, one `hygiene-message-home-path`, pinned in `data/expected/hygiene-history-pinned.ids`) are accepted by a delegated decision without a rewrite; the matched text is the shape of a scratch-directory path. The audited tree (HEAD) holds no such path (`git grep` for a home-directory prefix, a scratch-directory prefix, `/tmp/claude-<digits>` over HEAD is empty). A rewrite is an owner-only hard stop; the owner may veto the disposition.
- **R-08-D (low):** 18 `<stage2>` placeholders remain in `08-MILESTONE-CLOSE.md` by design (stage 2 of REL-01 follows the merge); the placeholder check is a documented command, not a gate step.
- **R-08-E (low):** the committed performance baseline was recorded on a host that was not idle; the record, `docs/bench.md` and the requirement note say so, and no check or claim relies on a number.
- **R-08-F (info):** the libFuzzer target `ivs_fuzz_snapshot` is built only on request and run by no gate or CI job; its absence from CI is the declared design (T-08-36) and no fuzz-run evidence is claimed.
