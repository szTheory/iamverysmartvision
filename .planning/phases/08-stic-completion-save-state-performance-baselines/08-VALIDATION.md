## Sampling Rate

- **After every task commit:** the task's own `<automated>` verify command, which always includes the exact gate-line tokens of that commit (counts move in the commit that causes them).
- **After every plan:** `sh tools/gate.sh` and `dash tools/gate.sh` with the plan's exact counts; `sh tools/gate-linux.sh` for plans adding C, shell or cmake (the plan names it).
- **Oracle-first:** derivation, frame literals, `.expect` text, checklist, container specification and schema literal are committed before any code that renders, serializes or restores them (waves A and B); the verifier checks `git log` order and that frozen sections are unchanged since the blind-read commit.
- **Digest before throughput:** `ivs-bench` verifies the report against the committed golden before any clock is read; the gate never runs the timed path.
- **Before `/gsd-verify-work`:** gate green under sh, dash and the container with the final counts above; hosted `gate_s`/`cpu_s` rows recorded by the orchestrator; cost checkpoints A, B, C evaluated; stage 2 of REL-01 is orchestrator evidence, never an executor claim.
- **Max feedback latency:** local quick samples under 10 s; hosted gate within the CI-EFFICIENCY budget.
