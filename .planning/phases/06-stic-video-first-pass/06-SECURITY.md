## Residual risks (non-blocking, below `block_on: high` or without a declared mitigation)

1. **Operator-path trust carried from Phase 4 and 5.** `--update-golden` still uses `fopen(path, "w")` (`main.c:412`: truncates, follows symlinks) and content-directory symlinks are still followed. Phase 6 adds the refusal of an `--update-golden` path that names a video or PPM output (same string and same inode) but not a general policy. The new outputs are stricter (`O_EXCL`, 0600). Intermediate directory symlinks in an operator output path are followed, as for any shell redirection. Low.
2. **`--frame-ppm` on a run that delivers no frame leaves an empty file and exits 0.** Probe: a scenario run to tick 3000 with `--frame-ppm` ends `outcome pass` and leaves a 0-byte file mode 0600 (`exec.c:1166` returns silently when `have_last_slot` is false). `--video-raw` has the same behaviour and a test (`video-raw-empty-run`, mode 0600 asserted); the PPM case has no named test. No data is disclosed (the file is empty) and a harness failure still removes it. Low.
3. **Audio, write-log and WAV outputs are created mode 0644 (before umask)** as noted in `05-SECURITY.md`; Phase 6 chose 0600 for the video outputs only, because a frame can be derived art of owner content. A frame export of owner content is refused outright, so the 0600 mode protects project-authored frames only. Low.
4. **No named control proves the measured-tier rule.** `claim-measured-without-d10` exists (`claim.cmake:92-94`) and was confirmed in a scratch copy, but no directory under `tools/check/controls/` exercises it, so a regression of that one line would not be caught by `run-controls` (Phase 5 residual 4, unchanged; `claims-unknown-tier` covers a different line). Suggest adding a `claims-measured-without-d10` control. Low.
5. **Two test skips** (`tests-skipped=2`), accepted by the `tests-inventory` step as in Phases 4 and 5. Informational.
6. **Executor-written verification.** `06-VERIFICATION.md` says it is the executor's own record and an independent verifier run may replace it. This audit re-ran the gate and the cited suites, faults and probes itself, and did not use the record's gate lines as evidence. Informational.
