<objective>
Give the owner-local route a cartridge role and prove it: the runner's six derived-output refusals and the
snapshot rule exercised for `content cart user`, the round trip's digest equality proved live, and the
route's pass path run end to end on project-made files with an id that is shown able to fail.

Purpose: SCN-03 is what turns the wrap tool into a route a person can use. The research measured that the
runner is already role-generic, so this plan is mostly **proof** — but three things are genuinely new: the
route's optional `--cart`, the conditional `content cart user` insertion that keeps the no-cartridge path
byte-identical, and the liveness limbs that stop the equality and the pass path from passing vacuously.
Output: three `runner-process` ids, the suite's sixth argument, the `--cart` option in
`tools/owner-run.sh`, and the two operator pages.
