<objective>
Define the fixture-manifest schema (FND-04) and enforce it fail-closed, plus the tracked-file rights checks that back the provenance rule (FND-05 part): nothing under `refs/`, no `.env`, no ROM/PDF/image-like file unless it is a committed output of an effectively redistributable manifest, no unlisted file inside a fixture directory.

Purpose: AGENTS.md treats binaries, manuals and system images as rights-bearing; a hash proves identity, not rights. These checks make an accidental commit fail the gate.
Output: `docs/fixture-manifest.md`, `docs/RIGHTS.md`, the sample manifest, `manifests` and `files` steps, nine controls.
