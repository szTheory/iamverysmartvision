<objective>
Turn the three questions only the owner can answer into three handoff rows with real procedures, extend the
two pins in the claims step so the id set and each disposition stay enforced in both directions, and print the
ledger's row count on the step's pass line so the count is measured at every commit instead of quoted.

Purpose: the milestone's third exit criterion is that the owner-only questions are ledger rows, never
criteria — `evidence: none`, dispositioned, cited by no claim and by no phase exit criterion (GUARDRAILS V8).
A row that exists without a procedure is a question with no answer path; a row whose id is not pinned can be
deleted together with its evidence; and a row count that lives only in prose is the figure the project's own
rule says will go stale. This plan closes all three.
Output: three ledger rows with packet sections, the extended pins, and one new `handoffs=` stat on the claims
pass line.
</objective>
