# v0.3.0 scoping point 3 — rights, format and packaging policy

`[REC]` for the upstream freeze. Five decisions, each with a reversal condition, checked against
`docs/fixture-manifest.md`, `data/sources.json`, `docs/presentation.md` cl.2,
`runner/frame_export.c:12`, `tools/pcm/`, `.gitignore`, profile `cart_span $4000–$FFFF`.

**R-1 — the rights ledger is a second, question-shaped ledger, not a second manifest schema.**
`data/rights/<slug>.json`, one file per item, keys `id`, `item`, `disposition` ∈
{`cleared`,`refused`,`owner-local-only`}, `source` (a `SRC-` id or `null`), `taken` (`"nothing"` legal), `tokens` (spellings a refused item must never appear as),
`note`. Enforced as ids inside `files`/`manifests`, zero new steps: a `cleared` row with a `null` or
unresolvable `source` is refused; the other two may cite nothing. The naming limb is
token+scope, never a global grep: a refused row's `tokens` are refused in `core/src`, `runner/`,
`tools/` and the operator pages of `docs/`, with pre-existing hits pinned by `(token, path)` in
`data/expected/rights-pinned.ids` as `hygiene-history-pinned.ids` pins history — `cfg` already
sits in `binary-ext.txt` and `.gitignore` as a *refusal surface*, and removing it would delete
the refusal. Reversal: a question whose answer is a byte set becomes a fixture manifest.

**R-2 — the wrap tool states bytes, never a format.** `tools/flatwrap` (build-only, no install
rule, not a step) takes `<flat> <base> <out>` plus `--word-order hi-first|lo-first`, default
`hi-first`, the project's one wire order. Input is a byte length and a word order only; it names no other tool's
format and auto-detects nothing. Refusals: odd length; a word above `$03FF` after assembly; more
than 65,536 words; a base outside `$4000–$FFFF` or an image crossing it; an output inside the work
tree except under the ignored `refs/` (as `owner-run.sh`); an existing file. The output is derived material of rights-bearing
content: never committed (`*.ivsc` is already in `.gitignore` and `binary-ext.txt`), never a
golden, never a fixture with `committed:true`, never created by CI, never a claim artifact, and
no digest of it but on stdout. Reversal: an owner shows a flat image neither
order expresses.

**R-3 — no libretro header is vendored; the ABI subset is project-authored.** The shim needs
about six `retro_*` entry points, not a 200-symbol header, so `host/libretro_shim.h` states only
the subset this project implements and says *libretro-shaped*, never compatible. Rights-clean: nothing to licence, nothing to notice. If an exact header is
later required, read its licence text first, record `{url, text_sha256, accessed}` as
`licence_evidence`, vendor under `third_party/` with notices, and the manifest's effective-`yes`
rule governs it. Reversal: a real frontend loads the shim.

**R-4 — one palette, one definition; audio keeps one converter.** The shim links
`runner/frame_export.c` rather than copying the array; cl.2's guarantees extend verbatim:
labelled `not STIC colour data`, never in `core/src`, never in a golden, digest, assert or
claim, no capture option for `content <role> user`. Audio: the shim reuses
`tools/pcm/ivs_refpcm.c` (build-only, uninstalled) and consumes the 4-byte sample from the
public headers; a second converter is refused by review. Reversal: a host needs
a colour table — cl.6's sourced field.

**R-5 — packaging names the shared object as a non-member.**
`binary-ext.txt` gains `so`, `dylib`, `dll`, `bundle` (a tracked shared library refused by name;
control `files-unlisted-binary-so`). The build-only shared target is the only place `IVS_API` is defined
(`target_compile_definitions`); the installed headers keep it empty, D-35's static-only package
stands, `pkg-install-files.ids` stays 11 paths with a selftest that the `.so` is absent, and
`release-assets` needs only its priced case — an extra member is already `install-extra-member`. The release-decision line reads: *the release
ships the static package and the source archive; no shared object, no host shim, no content.*
Core-info strings are project-authored and carry no trademark. Reversal: a decision to
ship a shared core, which moves `pkg-install-files.ids` and `docs/packaging.md` in the same commit.
