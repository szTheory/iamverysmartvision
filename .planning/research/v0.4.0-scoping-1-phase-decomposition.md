## 1.4 Drop and degradation (pre-authorized, written in the close record)

`18-03` drops whole: no disassembly subcommand, no `asm` round-trip id, no fourth
`asm-tap.sh` argument. `docs/inspection.md`'s disassembly section is then marked
"not built; a reader uses the committed listings under `tests/asm/`", TOOL-02
exits with the reduced surface named, and VID-07 and EV-08 are unaffected.

Phase 19 degrades only to its second honest exit: "default unchanged, observation
appended, rivals named". It is not a failure and it mints nothing.

## 1.5 The throwaway probe, and why it is not a gate step

`19-02` sits **inside** Phase 19, after `19-01` and before `19-03`, under `refs/`
only, bounded by a wall-clock limit and a run count, with its output refused
outside `refs/` (the `tools/flatwrap` precedent). It is not a gate step because
its input is owner-local content under D11: it is `skip-ok` (exit 13,
`missing-fixture`) in both inventories, it mints no claim, and its output is a
TOOL-09 rights-bearing operator artifact.

## 1.6 Ordering risk

The trace limb (`18-02`) is **not** droppable: it is Phase 19's load-bearing
dependency. If `18-02` is late or fails its liveness guard, Phase 19 is
**deferred whole to v0.4.1**, never re-planned into a reasoned fix — a default
chosen without an instrument is fitted, not discriminated. Phase 20 still lands,
with the VID-08 packet naming the trace lines as *specified* in
`docs/inspection.md` and marked "unproduced by instrument".

## 1.7 The plan-level failure modes this decomposition pre-empts

The v0.3.0 defect class was one shape: an automated gate a correct implementation
cannot satisfy (`.planning/RETROSPECTIVE.md`, v0.3.0 close). Five rules go into
every plan of this milestone:

- **F1** every count gate prints `<file>:<count>` against a **named** path;
- **F2** every baseline names the plan's own start commit sha and is measured
  there;
- **F3** no verify block decides an outcome by a pipeline tail;
- **F4** an id, its pending-line deletion, its registry row and its inventory
  line land in one commit;
- **F5** every new capability ships its liveness guard and a stand-in shown
  failing, and `pkg-install-files.ids` stays 11 so the tool cannot be installed
  by accident.
