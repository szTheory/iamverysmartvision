# v0.4.0 scoping — Decision point 4: verification strategy (FROZEN)

**Status:** frozen upstream policy, 2026-11-26, written before any Phase 17 plan
exists. Cite by section. Binds every plan, executor and verifier of v0.4.0.

## 4.1 The seams this milestone verifies *through*, not around

`[OBS]` A per-unit cycle-stamped access trace already exists in the core, and its
own contract states that the machine state, the log and the samples do not depend
on it. `[OBS]` The side-effect-free read path is `ivs_machine_peek` in
`core/include/ivs/ivs_run.h`. `[OBS]` Process-level tool checks are already ctest
ids (`tests/CMakeLists.txt` registers the assembler that way).

**Frozen:** TOOL-02's trace is a *wrapper* over those two seams in a build-only
executable shaped exactly like `tools/flatwrap` (no install rule, an explicit
source list, linking the internal core target). **The core gains no new function,
no sink and no file I/O**, and the installed list stays the 11 rows of
`data/expected/pkg-install-files.ids`.

## 4.3 Liveness guards, and the stand-ins that must make them fail

Every guard is a positive count or relation, never a bare `exit 0`. Each ships
with a committed scratch stand-in proving **the guard** — not the comparison —
fails.

| Capability | Guard | Stand-in that must fail it |
|---|---|---|
| access trace | records > 0; ticks non-decreasing; last tick equals the report's `step.*` end; `digest.*` byte-identical to the same scenario run untraced | (a) an emitter returning 0 records fails the empty guard; (b) an emitter repeating one tick fails monotonicity and the count; (c) a "tracing" build that pokes a register fails digest identity |
| disassembly round trip | words > 0, instructions > 0, at least one two-word form and one immediate present, re-assembled bytes equal the input bytes | (d) a constant-mnemonic disassembler fails byte equality; (e) an operand-dropping one fails length; (f) comparing the disassembler to itself is rejected because the comparator is a distinct binary and the reference is the input file |
| breakpoint | hit count equals 1 for a unique PC and 0 for an unreached PC, both asserted | a matcher that always hits fails the 0 case |
| discrimination | the diagonal of 4.4 | a field that moves no guest, or moves two |
| flatwrap to shim join | the shim's cartridge slot digest equals the container the wrap tool wrote, in the same test | a shim ignoring its input mismatches |

## 4.4 The four rival rules: the discrimination design

`[OBS]` The rivals are profile fields, not prose: the register-window length
(2000 against 2900), the gating-when-display-off rule (`apply` against `open`),
the `$0020` access effect (a read against a write), and the display latch (cleared
at frame start against persisting). All four are `unknown-default-chosen` in
`data/profiles/intv-2609-ntsc-family-p1.json`.

**Frozen design: four authored guests, one observable each, the four fields swept
as 2^4 = 16 cells.**

| Guest | What it does | Observable | Isolates |
|---|---|---|---|
| G1 | one WRITE to `$0020` at cycle c with 2000 < c < 2900, frame 0 only | frame 0 `displayed` | the window length |
| G2 | one WRITE to a non-strobe register at cycle 3500, outside **both** candidates, latch clear | `stic.blocked_writes` | gating when the display is off |
| G3 | one READ of `$0020` at cycle 100, no write, frame 0 | frame 0 `displayed` | read against write |
| G4 | one WRITE to `$0020` at cycle 100, never re-strobed | `displayed` for frames 0, 1 and 2 | latch persistence |

The observables are machine state assertable headlessly — `displayed`, a counter,
a register word — **never a pixel and never a human**.

**What proves *distinguishable*, not merely *different*:** the 16-cell sweep must
be **diagonal**. G1's observation changes if and only if field 1 flips, G2's if
and only if field 2 flips, and so on, with the other three held at their default.
Byte-differing traces prove nothing, because different guests differ trivially;
the required evidence is one-field sensitivity per guest plus pairwise-distinct
trace lines at the default. A guest that moves under two fields is a design
defect, not a finding, and is re-derived.

## 4.5 Pinning the decided default, and the blast radius

**The C41/D-51 precedent, frozen:** a decided value is pinned by **two ids**, one
per setting, each building the alternate parameter row explicitly — never one id
looping internally. The field stays tagged `unknown-default-chosen` and the
observation mints no claim.

**The blast radius is enumerated *before* the commit**, mechanically, and the
commit's file list must equal the enumeration; a mismatch is a stop, not a
re-bless. The chain is: `data/profiles/*.json` -> `data/expected/profile-fields.ids`
-> the profile parameter digest -> **every** snapshot literal in
`data/expected/ivsn-literals.ids` -> any golden whose expectation moves (goldens
stay **29**, so a moved golden is retargeted, never added) -> the C-row amended
**append-only** in `data/discrepancies.json` -> every claim citing the field -> the
prose stating the dropped or re-strobed rule. The enumeration is a throwaway probe
whose output is committed into the phase record, plus one `mutant` row over an
existing selftest proving that a *missing* retarget fails the enumeration check.

## 4.6 What the owner-local sweep may and may not record

**May:** the route command, the scenario id, the machine-state asserts the run
printed, and which of the 16 cells the run's behaviour is consistent with — as an
observation appended to the discrepancy row, naming the rivals.

**May not:** any digest, hash, size, path or name of an operator file; any claim,
tier or golden; any artifact inside the work tree except under `refs/`; any
pass/fail line the gate reads. A sweep that ends inconclusive is a valid exit and
is recorded as `default unchanged, observation appended, rivals named`.

## 4.7 Zero human UAT

Every limb above is a machine observation. The only human acts are D10-VID-08 (a
hardware probe: a handoff row with `evidence: none`, cited by no claim) and the
owner-local sweep, which is a throwaway probe and not a gate input. **No phase
exit criterion may name either.**
