## The fake frontend, without a window

One binary in `runner-process` `dlopen`s `build/<preset>/host/libivs_retro.so` (`.dylib` on
Apple), path from CMake, and resolves the eight `retro_*` entries of the project-authored subset
(`api_version`, `init`, `deinit`, `set_environment`, `get_system_av_info`, `load_game`, `run`,
`unload_game`) plus a harness-only `ivs_retro_digest(domain,out32)`. It asserts: version; a denied
environment command refused, not ignored; `av_info` equal to `ivs_info`; an index-plane frame of `width*height` bytes at the declared pitch; one project cartridge (boot
stub, zero GROM, `diag-cpu-1.ivsc`); a poll callback returning the scenario's words; and
`frames>0 && samples>0`.

**Digest equality, guarded three ways.** (1) All nine lines non-`-`, observed set equal — the
`pkg-install` rule, reused. (2) A second id runs with an empty poll and requires a **different**
set, so a constant-comparing judge fails. (3) Two stand-ins: a stub printing the golden verbatim
but delivering no frame must be refused `host-vacuous`; a mutant with the input poll dropped must
be refused `host-digest-diff`.

## Refusals beside positives; the owner PASS path

Each refusal sits beside its boundary positive: odd↔even length, `$0400`↔`$03FF`, 65,537↔65,536
words, base `$3FFF`↔`$4000`, crossing `$10000`↔ending at it, in-tree↔outside output, existing↔new. Zero-filled 8192/2048-byte
files are shape-legal, so the pass path runs on project-made inputs: banner, temp copy outside the tree, no output file, exit code = the runner's;
the id **pins the outcome the zeros give**, and a one-byte EXEC mutation proves it can fail. The
cartridge variant puts the project diagnostic in as `content cart user`; the `exec:` label stays
`-`, so no run reads as a real-EXEC result.

## Not in CI

`retroarch` or any real frontend; anything needing `refs/` or an owner image; `--source-route`
(release-time); a sanitizer lane for the shim (the core's ASan path covers it; no distinct class);
per-id rebuilds; an `nm` dump; a shim audio listen — throwaway probes, not CI.

owner image's picture and sound look right", "the owner's flat image needs no word-order guess".
