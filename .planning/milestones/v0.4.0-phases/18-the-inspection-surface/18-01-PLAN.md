    held to. Sections, in this order, with these contents:

    `# The inspection surface` - one paragraph: a build-only, scripted, headless instrument over seams the core
    already exposes; one binary named `ivs-inspect`; never installed; its output is an operator-local,
    rights-bearing artifact; it mints no claim.

    `## What it is built on` - the five seams, each named with its file: `ivs_machine_peek` and
    `ivs_machine_cpu_state` (public, side-effect-free reads), `ivs_machine_state_digest` (public, the nine
    domains the report prints), `ivs_machine_step_unit_trace_internal` (internal, the per-unit access trace the
    `psg`, `stic` and `machine` suites already drive through `core/src/machine/machine.h`, bounded by
    `IVS_CP1610_MAX_ACCESSES`), and the runner library - `ivs_scenario_parse` and `ivs_runner_execute`, with the
    report's bytes arriving through the host's `write_report` and `ivs_runner_report_write` named as the library's
    own writer behind it, never as a call the tool makes. Then the forcing sentence, in full: the
    report comes from the library because a second report writer would be a second truth, and the trace comes
    from the tool's own per-unit loop because the executor steps through the public run call with no access log
    and its state struct is static inside `runner/exec.c` - so the two passes cannot come from one call, and the
    reconciliation below is what makes them provably the same run.

    `## Command surface` - one binary, four subcommands, each with its grammar and its exit rule. `trace <scenario>
    --content-dir <dir> --out <file.ivst> [--report <file>] [--break <HHHH> --other <HHHH>]`; `break --pc <HHHH>
    --other <HHHH> --trace <file.ivst> --out <file>`; `dis <listing> --out <file.asm>`; `step <scenario>
    --content-dir <dir> --units <n> [--peek <HHHH> <count>]`. State the three exit statuses: 0 when the work is
    done, 1 for a named refusal (one stderr line prefixed `ivs-inspect: ` with the token, nothing on stdout, no
    output file left behind), 2 for a usage or file error, which carries no token. State that `--report` makes
    `trace` reconcile against a stored report instead of the one this run prints, and that the four subcommands
    are the whole surface - a fifth name is a usage error, never a quiet alias. `--help` is part of that surface and
    is pinned by name, not left to the implementer: it prints the four subcommand names and their grammars on
    stdout, prints no refusal token, and exits 0 - so `18-02`'s help id implements a sentence this page froze rather
    than one it invented while implementing it. Then pin the `step` report, because
    `18-02` asserts these keys by name: one `key value` line each, in this order, `step.units`, `step.ticks`,
    `step.halted` (`yes` or `no`), `step.pc`, `step.reg.R0` through `step.reg.R7`, and one `step.mem.<AAAA>` line per
    peeked word - addresses and values as four upper-case hex digits, counts decimal.

    `## The trace file` - the extension `ivst`, ASCII, one record per line, LF, decimal fields except `addr` and
    `value` which are four upper-case hex digits. Three record kinds and their exact field order. An access
    record: `tick=` first, then `kind=`, `addr=`, `value=`, `wait=`, `cycle=`, `unit_start=`, `unit_end=`; the
    nine `kind` values are the nine `IVS_ACC_*` names lower-cased, hyphenated for the two strobes; `tick` is
    `unit_start + cycle * ticks_per_cpu_cycle` with the multiplier read from the profile's timebase and never
    hard-coded. A step record: `step=<k> target=<n> end=<n> stop=<target|halted|faulted>`, one per run-to, `k`
    counting from 1. An end record, last: `end tick=<n> records=<n> units=<n> steps=<k> break_pc=<HHHH|none>
    break_hits=<n> other_pc=<HHHH|none> other_hits=<n>`; `records` counts access records only, so it is a real
    number to assert even though `end` is a line. Then the O1 resolution in one unambiguous paragraph: the
    frozen criterion's "the last record's tick" is the **`end` record's** tick; it equals the last step record's
    `end`, which equals the report's `step.<k>.now_ticks`; an access record keeps its own cycle stamp, so the
    trace is cycle-stamped **and** the equality is literally true. Say plainly that the alternative reading -
    making every record's `tick` the unit end - was refused because it loses the per-access cycle stamp the
    requirement names.

    `## The reconciliation` - the five equalities the tool requires before it reports success: the nine
    `digest.*` lines of its report are byte-identical to `ivs-run`'s for the same scenario; the nine digests of
    its traced instance, computed with `ivs_machine_state_digest`, equal the report's nine; each step record's
    `end` equals `step.<k>.now_ticks`; the end record's `tick` equals the last step record's `end`; access ticks
    are non-decreasing **and not all equal**, so at least two distinct tick values must appear - monotonicity alone
    is satisfied by a trace that repeats one tick and therefore asserts nothing, and the committed stand-in that
    repeats one tick is judged by this fifth equality. A failure is the refusal `inspect-reconcile` with exit 1 and
    no output file - never a warning and never a printed trace, because a trace that disagrees with the report is
    worse than none.

    `## Breakpoints` - a hit is an access at the named address whose `kind` is `fetch` or `iab` (the reset entry
    is an `IAB` with the reset flag, not a `fetch`, so both must count or the entry reads as never executed);
    one report prints the hit count at `--pc` **and** the hit count at `--other`, so a matcher that always hits
    cannot pass both; arming a breakpoint changes no access record and no digest, which is a separate equality
    from the trace's own and is asserted separately. Then pin the break report, because `18-02` asserts these keys
    by name: one `key value` line each, in this order, `break.pc`, `break.hits`, `break.other.pc`,
    `break.other.hits`, `break.records`, `break.end_tick`, `break.steps` - addresses as four upper-case hex digits,
    counts decimal, and the last three copied from the trace's own `end` record so the two documents can be
    compared rather than trusted.

    `## Disassembly` - the corpus is the project's own listings, registered in `data/expected/listings.ids`; the
    mnemonic is the `ROW` column and the operands are the following `-` rows plus the field groups of the `BITS`
    column, so no second decoder table exists; a row the tool does not know is the refusal `inspect-dis-row`
    (fail-closed, and falsifiable the moment the corpus grows); the re-assembler oracle is `ivs_asm` and the
    comparison is `ivs_pack --dump-words`, never listing text. Then pin the derivation, because `18-03` implements
    it and a cut it has to guess is a cut that silently emits a source assembling to different words: the emitted
    source's header is the listing's **leading run of `# key: value` lines whose key is one of the eight `ivs_asm`
    accepts** (`id`, `kind`, `contract`, `profile`, `window`, `label`, `entry`, `stack`), copied verbatim, and every
    other `#` line is dropped, because the assembler's header block ends at the first line that is not one of those
    (a bare `#` or a prose line is `asm-header`, not a comment); the operand text is the listing's own `ASM` column
    with the trailing note cut at the first run of two or more spaces, the branch or jump target annotation cut at
    ` -> `, and the leading token dropped **only** when it repeats the row field - where it does not, the `ASM`
    column on that line is a note and the mnemonic stands alone; and an `ORG $HHHH` directive is emitted before the
    first instruction and wherever the address is not the previous instruction's address plus its word count, so a
    gap is preserved rather than silently packed. Then the drop's reversal condition, stated as the authorisation
    it is: the limb may be dropped **only** if it cannot round-trip a corpus containing a two-word form and an
    immediate inside the priced line, and then this section is amended by an appended note reading that the limb is
    not built and a reader uses the committed listings; dropping it for schedule reasons is not authorised.

    `## Refusal tokens` - the five tokens, each as the first text on its own line, with two sentences beneath it
    (the trigger, and the boundary that must still be accepted). In this order: `inspect-output-tree` (an
    output whose physical parent lies inside the work tree and not under `refs/`, whatever the spelling - while
    an output outside the tree and any path under `refs/` is accepted); `inspect-output-exists` (the path exists,
    a dangling symlink included, and the refused run leaves it byte-identical - while a new path is created
    exclusively); `inspect-reconcile` (one of the five equalities above fails - while a run that satisfies all
    five writes its trace and exits 0); `inspect-break-empty` (`break` on a trace with zero access records -
    while a trace with one record yields a count of 1 or 0 and is not refused); `inspect-dis-row` (a listing row
    the disassembler does not know - while every row the boot-stub corpus uses is decoded). This block is
    machine-read by a later id, so each token appears exactly once inside it and the block is bounded by the
    `## Liveness guards` heading.

    `## Liveness guards` - four, each with the stand-in that shows it can fail: the end-tick equality against the
    report's own `step.<k>.now_ticks` (a trace that steps to the target instead of to the stop prints 16000 for
    a run that ended at 2084); the nine-digest equality (a "tracing" pass that pokes a register diverges on one
    domain by name); the breakpoint pair's zero case (a matcher that always hits reports 1 where the answer is
    0); the round trip's `words > 0` with at least one two-word form and one immediate (a `DECLE`-everything
    emitter round-trips perfectly and disassembles nothing).

    `## Rights` - one `owner-local-only` row with nothing taken; `ivst` refused by name in
    `tools/check/binary-ext.txt` and in `.gitignore`; an output inside the work tree refused except under the
    ignored `refs/`; and the sentence that nothing the tool writes is ever committed - not a golden, not a
    fixture, not a CI artifact, not a claim artifact - whatever its content.

    `## What this instrument is not` - no frontend and no window; no new core function, sink or installed file;
    no second decoder table; no claim. Name Phase 19 as the consumer that decides a display-path default by
    discrimination with it.

    Prose discipline, because the gate enforces it on this page: no claim word on a line without `[nc]` on the

    the ASCII-only set, so the page may use the em dashes and the arrows its neighbours use.
