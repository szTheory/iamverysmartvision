# Literal framing of the raw video chain for the first two display-off frames of profile intv-2609-ntsc-family-p1 (D-13, D-16; plan 06-01).
#
# This file is an independent recipe, not hardware evidence: the values are repeatability of a hand-framed byte string computed with POSIX
# sh, printf, head, cat and cmake -E sha256sum, never with the core, the runner or a generated include. They are the expected values of
# the first display-off scenario of plan 06-09 (a frame with the display never strobed, a plane filled with the border color index 0).
#
# Framing of one slot (big-endian, 32-byte header then the plane): be64(tick) || be64(index) || be32(width) || be32(height) ||
# be32(flags) || be32(0) || plane, flags bit 0 = displayed. For the display-off frames flags is 0, width is 159, height is 96 and the
# plane is 15,264 bytes of 00 (the border color index 0). Slot 0 is the frame that ends at tick 59,736 (hex 000000000000E958), slot 1 the
# frame that ends at tick 119,472 (hex 000000000001D2B0). The chain is h0 = SHA-256 of the 16 ASCII bytes IVS-VIDEO-LOG-V1 and
# h(n+1) = SHA-256(h(n) as 32 raw bytes || slot n).
#
