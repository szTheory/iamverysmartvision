# Requirements (control tree)

Toy record for the control tree: a Traceability table listing exactly the requirement ids
the toy registry data/expected/important-gates.ids covers, every one of them Complete. It is
deliberately minimal and is never a copy of a real record, so the good-tree positive control
is consistent by construction: the derived must-be-covered set equals the toy registry.
