#
# Claim tier: tier4-community, one lineage. No manufacturer page prints a MOB register bit (08-DISCUSS-stic.md section 2; the pages of
# SRC-gi-1980-catalog print only that 8 foreground objects exist), and the community wiki STIC page has no MOB register figure. The roles below are a
# transcription of the register-layout text of SRC-community-emu-docs (the register description of the STIC, read raw in plan 08-03 and logged in
# docs/provenance/CONSULTATIONS.md); no figure, table or sentence of it is kept here, only one role per bit in the project's own words. It is never
# derived from, generated from or edited to match the core. A pass of the video step shows the file is complete, not that the layout is right.
# Its negative proof is the in-process judge video.judge.mob-role-swapped of plan 08-04 (two roles swapped must fail the comparison), as for the
# cards literal, which has no gate control either.
#
# Registers: mobx (X register: position, interaction enable, visible, double width), moby (Y register: position, tall mode, Y size, mirrors),
# moba (attribute register: color, card number, graphics RAM select, priority). Stored widths agree with data/stic/*.regmap.literal.txt
# (X 11 bits, Y 12 bits, attribute 14 bits): every bit above the width is ign.
# Row grammar (one row per line, single spaces): <register> <bit 0..15> <role> then the source key (src, an equals sign, <SRC-id>@<locator>),
# tag=tier4-community and conf=C81. Forty-eight rows: each register has the sixteen bits 0 to 15 once.
# Roles: ign (not used), posN (bit N of the position), intr (interaction enable), visb (visible), xsize (double width), yres (tall mode: 16 pattern
# rows from two cards), ysiz2 and ysiz4 (the two Y size bits that give the displayed height with yres), xflip and yflip (mirrors), colorN (bit N of
# the color, bit 3 at attribute bit 12), cardN (bit N of the card number at attribute bits 3..10; bits 6 and 7, attribute bits 9 and 10, are ignored for
# a graphics RAM card, and bit 0 is ignored in tall mode), sel (graphics RAM 1 or ROM 0), prio (behind the background cards when set).
