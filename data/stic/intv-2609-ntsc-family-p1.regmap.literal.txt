# Literal STIC register-address map of profile intv-2609-ntsc-family-p1 (D-02, D-04; C81, C82, C86; plan 06-01).
#
# Claim tier: tier4-community for the role and address of every row that a source names, unknown-default-chosen for the rows no source
# describes. This file is a transcription of the cached community wiki pages (SRC-intv-wiki, STIC-oldid-15008: the address table of the
# sixty-four registers with the role of each range; Memory-Map-oldid-14847: the access column that lists $0000-$003F as readable and
# writable). The manufacturer pages (SRC-gi-1980-catalog pdf 191..193, SRC-gi-1982-catalog pdf 462..464) print no register address
# (docs/stic/reference-notes.md, registers-printed: no). The w and r columns of a stored row are the stored width and the read-back
# model, both unknown-default-chosen (C86, C81): no source states the width of a register or what a read returns. A pass of the video step
# shows that the file is well formed and tiles the address space, not that the console behaves this way.
#
# Independence rule: this file is written from the sources only. It is never derived from, generated from or edited to match a profile
# field, a descriptor table or a core output it judges, and it names no profile field. Where a source and the profile differ, this file
# keeps the source reading and the profile is the side that changes. Emulator source code is never a source for a row.
#
# Row grammar (one row per line, single spaces, columns in this order, sixty-four rows in ascending address order):
#   <ADDR> role=<role> class=<stored|strobe|collision|reserved> w=<HHHH> r=<HHHH> then the source key (src, an equals sign,
#   <SRC-id>@<locator>), then tag=<tag> and conf=C<n>
#   ADDR   CPU word address 0000..003F, four uppercase hex digits, each exactly once.
#   role   the function of the register: mobN-x, mobN-y, mobN-attr, mobN-collision for N = 0..7, display-enable, mode-select,
#          color-stack-N for N = 0..3, border-color, h-delay, v-delay, border-ext, reserved.
#   class  stored keeps a masked value, collision keeps a masked value and reads it back, strobe stores nothing and has a machine-level
#          effect (plan 06-06), reserved stores nothing.
#   w, r   the write mask and the read mask of the 16-bit bus word. A store keeps value AND w. A read gives (store AND r) OR (fill AND
#          NOT r) with the undriven fill FFFF, so a row with r=0000 reads FFFF (C5, C81) and the collision rows read FC00 OR the stored
#          bits. Bits 15 and 14 are never stored (the STIC has 14 data pins, pdf 191).
#   src    the source id and the locator, written without a dot.
#   tag    tier4-community or unknown-default-chosen. conf is the discrepancy id that records the open part of the row.
